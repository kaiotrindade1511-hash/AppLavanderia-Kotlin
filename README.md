# AppLavanderia - Kotlin

## Estudo de Caso 10 - Aplicativo de Lavanderia

Projeto desenvolvido em Kotlin com o objetivo de simular o funcionamento de um aplicativo de lavanderia.

### Funcionalidades

- Cadastro das roupas
- Seleção do tipo de lavagem
- Cálculo do preço conforme o tipo de roupa
- Cálculo do peso total
- Opção de removedor de manchas
- Cálculo do frete
- Exibição do valor total do pedido

### Tecnologias utilizadas

- Kotlin
- IntelliJ IDEA

### Estrutura do projeto

O código principal do sistema está localizado em:

`src/Main.kt`
